# Lingualoop

Full-stack IELTS preparation platform with AI feedback across Writing, Reading, Speaking, and Listening.

## Stack

| Layer | Technology |
|-------|-----------|
| Backend | Laravel 11, PHP 8.3+ |
| Frontend | React 18 + TypeScript, Inertia.js v2, Vite |
| Database | SQLite (dev) · MySQL / PostgreSQL (prod) |
| AI grading & generation | Google Gemini (`gemini-2.5-flash-lite`) |
| TTS | ElevenLabs or Azure Speech (listening audio) |
| SRS | FSRS algorithm (vocabulary + drill cards) |

## Modules

| Module | Route | What it does |
|--------|-------|--------------|
| Writing | `/compose` | Essay submission · Gemini grading on TA / CC / LR / GRA · error taxonomy · drill cards · collocation detection |
| Reading | `/reading` | Timed comprehension passages · AI-graded Q&A |
| Speaking | `/speaking` | MediaRecorder audio upload · Gemini grading · collocation errors · AI examiner follow-up · vocab suggestions per topic |
| Listening | `/listening` | TTS-synthesised audio · comprehension questions · AI grading |
| Vocabulary | `/vocabulary` | Notebook · FSRS SRS flashcard review · AI example + CEFR detection |
| Image Description | `/images` | Describe charts, graphs, diagrams, maps, and photos — writing or speaking · multimodal Gemini grading · collocation check · key-features coverage |
| Mock Exam | `/mock` | 65-min timed hub drawing randomly from all four skills |
| Drills | `/drill` | FSRS flashcard session from writing error cards |
| Profile | `/profile` | Error stratigraphy · score sparklines · 20-badge achievement system |
| Dashboard | `/dashboard` | Admin panel — generate reading / speaking / writing content via Gemini |

## Quick Start

### Requirements

- PHP 8.3+, Composer 2
- Node 20+, npm

### Install

```bash
git clone <repo-url>
cd lingualoop-app
composer install
npm install
cp .env.example .env
php artisan key:generate
```

### Configure `.env`

Minimum for local dev (AI disabled):

```env
APP_URL=http://localhost:8000
DB_CONNECTION=sqlite

GRADING_DRIVER=stub        # 'gemini' for real AI grading
GEMINI_API_KEY=            # required when GRADING_DRIVER=gemini

ELEVENLABS_API_KEY=        # required for listening audio playback
```

### Run

```bash
php artisan migrate --seed
php artisan serve          # backend on :8000
npm run dev                # Vite HMR on :5173
```

Open http://localhost:8000, register, and start practising.

### Run tests

```bash
php artisan test
# or target a suite
./vendor/bin/phpunit --testsuite Feature
./vendor/bin/phpunit --testsuite Unit
```

Tests use in-memory SQLite and `GRADING_DRIVER=stub` — no API keys needed.

## Environment Variables

| Variable | Default | Description |
|----------|---------|-------------|
| `APP_KEY` | — | Generated by `php artisan key:generate` |
| `APP_URL` | `http://localhost` | Full base URL |
| `DB_CONNECTION` | `sqlite` | `sqlite`, `mysql`, or `pgsql` |
| `DB_DATABASE` | `database/database.sqlite` | SQLite file path or DB name |
| `GRADING_DRIVER` | `stub` | `gemini` calls Gemini; `stub` returns instant fake grades |
| `GEMINI_API_KEY` | — | Google AI Studio API key |
| `GEMINI_MODEL` | `gemini-2.5-flash-lite` | Model ID |
| `ELEVENLABS_API_KEY` | — | ElevenLabs key (free: 10k chars/month) |
| `ELEVENLABS_VOICE_ID` | `21m00Tcm4TlvDq8ikWAM` | Voice ID — default is Rachel (American female) |
| `ELEVENLABS_MODEL` | `eleven_turbo_v2_5` | ElevenLabs model |
| `AZURE_TTS_KEY` | — | Azure Speech key (alternative to ElevenLabs) |
| `AZURE_TTS_REGION` | `eastus` | Azure region |
| `AZURE_TTS_VOICE` | `en-GB-SoniaNeural` | Azure Neural voice name |
